BO7 Zombies Loadouts Beginners Guide

By Joemet123 · 2026-10-08

Work In Progress: This guide is still being checked and expanded, so some details may change.

Everything about BO7 Zombies loadouts, in the order you use it.

Unlock Loadouts

  • Reach level 4.
  • Lobby, top tabs, Loadouts.
  • Early on: few weapons and attachments.

Field Upgrade, Lethal, Tactical

  • Pick any from each list.
  • Field upgrade example: Healing Aura.

Melee

  • Default: knife.
  • Select and edit like any weapon.
  • Only the camo can be changed.

GobbleGum Pack

  • Scroll down. Gums are sorted by rarity and some sit below the visible list, Legendary ones like Crate Power included.
  • New gums added in BO7, some very strong.
  • Slots 1, 2 and 3 are your starting gums.
  • Slots 4 and 5 come from the GobbleGum machine in game only.

Move A Gum To Another Slot

  • No reorder option.
  • A gum already in your pack cannot be picked for another slot.
  1. Select the slot to fill.
  2. If the gum you want sits in another slot, put a different gum (not in your pack) into that slot first.
  3. Go back to the slot to fill and select the gum.

Main Weapon And Gunsmith

  • Change weapon: select the slot, pick a new weapon.
  • Edit, route 1: press the Gunsmith prompt at the bottom of the loadout screen.
  • Edit, route 2: weapon list, select weapon, Equip Weapon And Open Gunsmith.
  • Gunsmith: attachments and camos.

Zombie Builds

  • Weapons can have more than one saved version.
  • The version in your loadout slot is only what you spawn with.
  • A Zombie Build is the version you get from the wall or Mystery Box.
  1. Open the weapon.
  2. Hover the version you want.
  3. Press the input shown at the bottom of the screen (PC: 1).
  4. A purple Z marks it as your Zombie Build.
  • Wall buys and Mystery Box pulls give that version, even if you spawned with another.
  • Set a Zombie Build on every weapon as you unlock attachments, and keep editing.

Weapon Build Codes

  • Every weapon build has a build code.

Copy Your Code

  1. Open the weapon in the Gunsmith.
  2. Find the build code.
  3. PC: use the copy button.
  4. Paste it in Discord, social media or a video description.

Missing Attachments

  • The game warns you and offers two choices.
  • Equip The Current Build: uses your existing build, drops the locked attachment.
  • Duplicate The Build: saves a copy with every attachment you own, leaves out the rest.
  • Duplicate in almost every case. Once you unlock the missing attachments you can use the full build.

Import A Build

  1. Pick any weapon in the loadout menu.
  2. Press the weapon build code button.
  3. Type or paste the code. The attachments show.
  4. Save the shared build: Yes.
  • Added to that weapon's build list.
  • Attachments carry over. Camo does not.

Share With A Friend

  1. Hover the weapon in your loadout.
  2. Options, Share Weapon Build.
  3. Check your friends.
  • They get a notification in the top right.
  • Selecting it opens the import screen. They choose Save Weapon Build.
  • Not friends: send the build code from your Gunsmith, or from Options on the weapon.

Multiplayer

  • Builds and sharing work the same in multiplayer.
  • Share a class between Zombies and multiplayer.

Camos

  • Gunsmith, Customize, Camos.
  • Cosmetics do not copy when you share a build. Attachments only.
