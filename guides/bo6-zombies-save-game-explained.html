BO6 Zombies Save And Quit Explained

By Joemet123 · 2026-11-09

You Can Save Your Zombies Games For Up To 30 Days, And Even Recover Games You Crashed In.

Requirements

  1. It Can Only Be Done In Solo Games. Not Alone In A Private Match, Just A Straight Up Solo Game.
  2. You Need To Be At Full Health.
  3. Fresh Game: As Long As You're Past Round One, You Can Save.
  4. Resumed From A Previous Save: Proceed To The Next Round First. On Round Six, Just Go To Round Seven.

How To Save

  1. Pause The Game.
  2. Scroll Down And Hit Save And Quit.
  • You're Out Of The Game And You Have Your Save File.
  • The Save File Deletes After 30 Days.
  • You May Now Turn Your Console Off And Do Whatever You Want.

Loading A Save

  1. In The Zombies Main Menu, Hit Select Mission.
  2. Hit Save File.
  3. Then Select Your Game.

One Save At A Time

  • You Can Only Save One Game At A Time.
  • Once A New Save Is Made, The Old One Is Gone Forever.
  • Not Once You Go Into Another Game: Once You Create Another Save. You Can Play Another Solo Or Co-Op Game, On Any Map, Without Losing Your Save.
  • Have A Save You Want To Keep And Forced To End The Game You're In? Hit Leave Match, Not Save And Quit.
  • Sounds Stupid, But It's Easy To Do By Accident If You're Acting Quickly.

Pause Timer

  • You Only Have A 15 Minute Pause Timer, And This Is Per Session.
  • After That The Game Will Just Keep Going.
  • Save The Game And Go Back Into That Save File: The Timer Resets Back To 15.
  • Save Whenever You Can When The Pause Timer Starts To Get Lower.

Crashes

After A Crash, A Pop-Up Asks If You Want To Continue That Previous Game Or Discard It.

  • If You Continue: You Resume From Where You Left Off, But Your Existing Save File Is Replaced.
  • If You Discard: When You Go Into The Save File Section Of Select Mission, Your Save Should Still Be There.
  • If The Newer Game Is Something You Really Care About, Like A High Round, Continue It. If Your Older Save Is More Important To You, Discard The Current One.
  • This Does Bug Out Sometimes. If The File Isn't There, Do A Complete App Close, Restart The Game And Go Back.
  • Crash On The Round You Loaded Into: It Won't Create An Additional Save File. It Just Uses That Old Save File.
