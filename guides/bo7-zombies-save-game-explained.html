BO7 Zombies Save And Quit Explained

By Joemet123 · 2026-10-08

Work In Progress: This guide is still being checked and expanded, so some details may change.

A save puts you back at the start of the round you saved on.

What Gets Restored

  • End-of-round state comes back
  • Weapons, Pack-a-Punch upgrades and perks from the current round are lost
  • GobbleGums used this round stay used
  • Crash saves work the same way

Save And Quit Requirements

Pause menu, then Save And Quit. You need:

  1. Full health (any zombie damage blocks it until you recover)
  2. No active Exfil
  3. Not the round you loaded into (finish it first, the game shows which round)

Crash Recovery

  1. Relaunch Black Ops 7 and open Zombies
  2. Go to Select Match
  3. Pick Continue to resume from the start of the crash round, or Discard to delete it for good
  • You get one chance to continue
  • No Save And Quit on that round
  • Crash again before finishing it and the match is lost

Loading A Save

  1. Go to Select Match
  2. Open Save File
  3. Pick your save
  • Backing out keeps the save
  • Loading deletes the file
  • Crash on the round you resumed and the save is gone
  • Saves last up to 30 days

Save Slots

  • One regular save at a time
  • Survival and standard Zombies share it
  • Playing other standard games, including Ashes of the Damned, leaves it alone
  • Saving another standard game replaces it
  • Dead Ops Arcade 4 has its own slot, so both saves can exist together

Retrying Easter Egg Boss Fights

  • Down in the fight, get up, pause and save
  • You reload at the start of that round, before the fight

Tip

  • Bought something important mid-round? Play one more full round before saving
